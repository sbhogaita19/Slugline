# Slugline

Kyran Screenwriting Software. A screenwriting trainer that lays scripts out in industry format and coaches good habits.

Open the live app: https://sbhogaita19.github.io/Slugline/

Notes
- Everything runs in the browser. Scripts are saved on the device you use, not in this repo.
- Use Menu > Download as text to back up a script.
- The AI Mentor only works when the app is opened inside Claude. The formatting, Coach, outline, reports, drafts, find and replace, printing and downloads all work here.
